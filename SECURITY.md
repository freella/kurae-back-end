# Política de segurança

## Reportar uma vulnerabilidade

Não publique detalhes de vulnerabilidades em issues, discussões ou pull requests públicos.

Se **Report a vulnerability** estiver disponível na área **Security** deste repositório, use-a
para enviar o relato privadamente. Caso contrário, abra uma issue sem detalhes técnicos apenas
para solicitar um canal privado. Os mantenedores devem responder com instruções para continuar
a conversa em privado.

Inclua passos de reprodução, impacto observado e uma forma segura de contato. Não envie
credenciais reais nem dados pessoais de terceiros.

## Escopo e resposta

Esta política cobre o código e as configurações mantidos neste repositório. Não há prazo de
resposta ou acordo de nível de serviço publicado.
