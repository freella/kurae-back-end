# Política de segurança

## Reportar uma vulnerabilidade

Não publique detalhes de uma vulnerabilidade em uma issue, discussão ou pull request público.

Se a opção **Report a vulnerability** estiver disponível na área **Security** deste repositório,
use-a para enviar o relato de forma privada. Se a opção não estiver disponível, abra uma issue
sem detalhes técnicos apenas para solicitar um canal privado de contato. Os mantenedores devem
responder com instruções para continuar a comunicação em privado.

Inclua no relato privado os passos para reproduzir o problema, o impacto observado e uma forma
segura de contato. Não inclua credenciais reais ou dados pessoais de terceiros.

## Escopo

Esta política cobre o código e as configurações mantidos neste repositório. Não há prazo de
resposta ou acordo de nível de serviço publicado.
